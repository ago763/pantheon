## Ícone Pantheon

`pantheon-icon.png`: gerado com a ferramenta integrada image_gen.
`pantheon.ico`: conversão para os tamanhos 16, 24, 32, 48, 64, 128 e 256 usando `tools/build_icon.py`.
Aplicado na janela do Pygame, no executável via Pantheon.spec e no atalho da Área de Trabalho.
